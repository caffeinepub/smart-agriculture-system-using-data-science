# Smart Agriculture System - Frontend

A modern web application for smart agriculture using data science, built on the Internet Computer platform.

## Overview

This application provides three core modules to help farmers optimize their operations:

1. **Crop Yield Prediction** - Predict crop yields based on soil type, weather conditions, and fertilizer usage
2. **Plant Disease Detection** - Detect plant diseases from leaf images using AI
3. **Smart Irrigation Recommendation** - Get irrigation recommendations based on soil moisture and weather

## Prerequisites

- Node.js (v18 or higher)
- pnpm package manager
- DFX (Internet Computer SDK)
